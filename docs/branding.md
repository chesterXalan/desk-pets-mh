# Branding

The Mizutsune icon is AI-generated fan art, created with the built-in image generation tool.
Monster Hunter characters belong to CAPCOM.

- Source artwork: `Resources/Branding/AppIcon.png`
- macOS icon: `Resources/AppIcon.icns`, generated by `swift tools/make_icon.swift` and `make app`
- GitHub social preview: `Resources/Branding/SocialPreview.jpg` (1280 × 640)

The icon generator preserves transparency and creates the standard 16–1024 px macOS representations.
The app's bundle identifier, executable, installation path, and local data directory retain their existing names.

## Icon prompt

```text
Use case: logo-brand
Asset type: a single finished macOS application icon for MH Desk Pets, also used as the GitHub project logo
Primary request: a beautiful adorable chibi Mizutsune (泡狐龍 / タマミツネ) from Monster Hunter as the mascot
Subject: just one large expressive Mizutsune head and short curved neck, three-quarter view facing slightly left, cream-white fox-like dragon face, pink-magenta fin-shaped ears and crest, golden pale-yellow accents, a bright friendly teal eye, elegant small whiskers. Recognizable Mizutsune anatomy, cute and confident, compact strong silhouette
Style/medium: polished hand-painted game mascot icon, clean bold contours, restrained fine detail, soft cel shading, not pixel art, not photorealistic, no lettering
Composition: square 1024 x 1024 canvas. Centered macOS rounded-square tile occupying approximately 82 percent of the canvas with equal transparent padding outside it. The mascot fills most of the tile, with fins fully contained, readable at 32px. Deep midnight teal rounded-square background with a subtle luminous teal center and softly beveled edge; warm pink creature contrasts clearly. Two tiny iridescent bubbles tucked beside the lower neck, subordinate to the face. Gentle top-left light, subtle depth, clean professionally finished edges
Constraints: output exactly one standalone app icon, no contact sheet, no presentation mockup, no device, no text, no initials, no Monster Hunter or CAPCOM logo, no watermark. True transparent alpha outside the rounded square, including all four canvas corners
```

## Social preview prompt

The icon source above was supplied as the reference image. The result was resized to 1280 × 640
and exported as JPEG for GitHub's upload size limit.

```text
Use case: logo-brand
Asset type: GitHub repository social preview card, landscape 2:1 aspect ratio, 1280 by 640 layout
Input image: reference mascot/logo, preserve its Mizutsune head, colors, facial identity, teal rounded-square tile and transparent silhouette faithfully. Do not redesign the mascot.
Primary request: create an elegant minimal social sharing card for the open-source macOS app MH Desk Pets using this exact logo as the main visual.
Scene/backdrop: solid very dark midnight teal background with only a subtle soft teal halo behind the logo, no scenery.
Composition: the supplied complete icon occupies the left third with generous padding on all edges. On the right, large clean white modern sans-serif title on two lines, exact text 'MH Desk Pets', followed by a smaller pale teal subtitle on two lines, exact text 'Monster Hunter companions' and 'for Claude Code & Codex'. Keep all text and artwork well inside safe margins. Balanced calm professional spacing, no busy decorations.
Constraints: single flat finished 2:1 banner, not a mockup, no extra logos, no watermark, exact spelling, no extra text, preserve the input icon's visual identity
```
